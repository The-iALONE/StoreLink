# Changelog

## 1.0.0 — 2026-09-05

### Added
- Plugin bootstrap with modular architecture
- Bulk price editor with preview/apply workflow
- Advanced product filters (11 filters)
- Undo last bulk operation
- Operation history / audit log
- Excel import / export (XLSX)
- Dashboard with KPI stats
- REST API (`pricepilot/v1`)
- React admin UI with RTL support
- PHPUnit tests for pricing and validation
- HPOS compatibility declaration

### Requirements
- PHP 8.3+
- WordPress 6.6+
- WooCommerce 8.0+
